## Exercise 00 — Организация рабочей папки
**Что делать:** Придумать короткое название (префикс) для каждой задачи. Создать внутри `src` отдельную папку с этим названием.

**Зачем:** Чтобы все файлы по разным задачам лежали раздельно и не путались.

---

## Exercise 01 — Где брать информацию
**Что делать:** Составить список (в Excel) из 5+ источников информации по каждой задаче. Указать, что важно: название, ссылку, приоритет изучения, актуальность, заметки и т.д.

**Зачем:** В реальных проектах изначально мало данных. Учиться быстро находить и структурировать нужную информацию.

---

## Exercise 02 — Словарь терминов (глоссарий)
**Что делать:** Создать таблицу с 10+ терминами по каждой задаче. Для каждого термина — определение, источник, дата добавления (номер проекта).

**Зачем:** Чтобы все участники проекта одинаково понимали ключевые слова, не было путаницы.

---

## Exercise 03 — Разбираем на части на примере пирамиды населения
**Что делать:** Найти демографическую пирамиду РФ. Определить:
- по какому признаку она разбита (показатель)
- зачем она составлена (цель)
- какой это тип декомпозиции
- сколько уровней и какие критерии на каждом
- порядок построения

**Зачем:** Понять базовые понятия декомпозиции на готовом примере, прежде чем делать свою.

---

## Exercise 04 — Исправляем чужую декомпозицию (завтрак)
**Что делать:** Посмотреть на кривую схему «Завтрак». Определить цель и тип декомпозиции, найти ошибки, исправить их. Затем сделать объектную декомпозицию завтрака (по частям/предметам) до 2 уровня.

**Зачем:** Научиться замечать нарушения правил (пересечения, неполноту, разный критерий) и строить правильную структуру.

---

## Exercise 05 — Декомпозиция для задачи «Доставка»
**Что делать:** По задаче про доставку:
- разбить на части действия курьера (цель, вид, уровни)
- отдельно сделать объектную декомпозицию ролей (кто участвует)

**Зачем:** Применить декомпозицию к реальной бизнес-задаче, потренироваться выбирать вид под цель.

---

## Exercise 06 — Декомпозиция собственного дня
**Что делать:** Выписать 10+ дел за день. Придумать 2 разные цели (например, «как оптимизировать время» и «что отнимает энергию»). Для каждой цели — кто пользователь и зачем ему это. Построить событийную декомпозицию по правилам.

**Зачем:** Освоить главный навык аналитика — умение разбивать сложное на простые части. Проверить на себе, как работают правила.
