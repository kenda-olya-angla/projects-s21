## Exercise 00 — Кто участвует в проекте (каталог стейкхолдеров)
**Что делать:** Для задачи про доставку создать Excel-таблицу со списком всех заинтересованных сторон. Выбрать характеристики для описания (например, организация, роль, уровень контакта с системой). Заполнить известные из задачи данные.

**Зачем:** Научиться системно выявлять всех, кто влияет на систему или зависит от неё, чтобы никого не упустить при сборе требований.

## Exercise 01 — Луковичная диаграмма
**Что делать:** Для задачи про доставку определить слои (круги) по степени близости к системе: кто внутри работает, кто взаимодействует, кто внешний. Разложить стейкхолдеров по этим слоям. Добавить тех, кого нет в задаче, но кто может быть в жизни. Нарисовать диаграмму.

**Зачем:** Визуально увидеть, кто к системе ближе, кто дальше. Это помогает понять степень влияния и приоритет работы с разными группами.

## Exercise 02 — Интересы, потребности, проблемы
**Что делать:** Для каждой задачи (барбершоп и доставка) сделать таблицу, где для каждого стейкхолдера выписать:
- что ему важно (интересы)
- что ему нужно от системы (потребности)
- с чем у него сейчас проблемы

**Зачем:** Стейкхолдеры заказывают систему не просто так. Чтобы система приносила пользу, нужно понять их боль и желания. Это основа для правильных требований.

## Exercise 03 — Пополнение словаря терминов
**Что делать:** Найти в тексте обеих задач новые термины и понятия, которых не было в глоссарии прошлого проекта. Добавить их в глоссарий с определениями и источником.

**Зачем:** В каждом проекте появляются новые термины по новой предметной области. Глоссарий должен расти и обновляться, чтобы все говорили на одном языке.
