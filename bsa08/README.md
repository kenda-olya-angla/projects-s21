## Exercise 00 — Вариант использования: создание расписания (без слотов)
**Что делать:** Для задачи про барбершоп описать UC (вариант использования) для сценария, чтобы в системе было актуальное расписание услуг мастеров (без учёта занятых/свободных слотов — просто список услуг и времени, которые мастер может оказывать). Описать: основное действующее лицо (кто инициирует), цель, идентификатор, название, другие заинтересованные стороны, предусловия, триггер, постусловия (минимальные гарантии и гарантии успеха).

**Зачем:** UC описывает не просто действие, а бизнес-цель. Здесь учимся выделять, кто зачем взаимодействует с системой, и фиксировать договорённости о поведении системы.
